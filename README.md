# 📚 Repositório de Estudos

Este repositório foi criado com o objetivo de **registrar meus estudos, práticas e aprendizados** na área de desenvolvimento de software. Aqui concentro códigos, exercícios, anotações e pequenos projetos desenvolvidos ao longo da minha jornada de aprendizado.

---

## 🎯 Objetivo

- Consolidar conhecimentos adquiridos em cursos, livros e documentações  
- Praticar conceitos teóricos por meio de código  
- Acompanhar minha evolução como desenvolvedora  
- Criar uma base de consulta para estudos futuros  

---

## 🗂 Estrutura do Repositório

A estrutura pode variar conforme os estudos, mas geralmente segue o seguinte padrão:

```bash
📦 estudos
 ┣ 📂 instituicao
 ┃  ┣ 📂 nome-do-curso
 ┃  ┃  ┣ 📜 README.md
 ┃  ┃  ┣ 📂 fundamentos
 ┃  ┃  ┣ 📂 exercicios
 ┃  ┃  ┣ 📂 projetos
 ┃  ┃  ┗ 📂 testes
 ┣ 📂 anotacoes
 ┗ 📜 README.md

```

---

### 📌 Descrição das pastas

- **instituicao/**  
  Contém os cursos organizados por instituição (faculdade, bootcamp, plataforma online, etc.).

- **nome-do-curso/**  
  Cada curso possui sua própria pasta, contendo:
  - `fundamentos/`: conceitos teóricos e exemplos básicos  
  - `exercicios/`: exercícios práticos  
  - `projetos/`: projetos aplicando os conhecimentos  
  - `testes/`: testes, experimentos e provas de conceito  
  - `README.md`: descrição específica do curso  

- **anotacoes/**  
  Anotações gerais, resumos, links úteis e materiais complementares em Markdown.
